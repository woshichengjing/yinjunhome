# 温控策略审查与修正（2026-09-11）

目标：舒适时避免自动启动，跑温时停止无效制冷，长期达标卸载后主动关机。
本次结论来自仓库代码审查和离线分钟级场景回放，未读取生产运行日志或操作 HA。

## 确认的问题

1. 跑温只在普通有人意图里处理，睡眠、待客和客餐厅共享空间可走舒适分支；执行层又信任意图覆盖其跑温兜底。
2. 环境允许同时输出“舒适”和“偏热”（裸温阈值与体感阈值不同），旧开机条件只看到“偏热”。
3. 待机先提交 `off`，随后调模式使用 `on`，可在同一轮覆盖关机队列。
4. 舒适会话只做记录，没有连续卸载关机；已舒适/偏冷时的设定点回升分支还有反向降低较高设定点的可能。
5. “运行中等到位”可被最后的强制压低覆盖，持续制冷时仍每分钟降低设定点。小于 0.3°C 的超标也存在重复降温通路。
6. 旧自动指令可排队 30 分钟；需求消失后不撤销，永久签名去重又可能吞掉后续重试。
7. 实时校准只更新开关，模式/设定点/回风仍使用上一轮快照；运行调节也可能唤醒用户刚关掉的设备。
8. 历史预冷窗口能取消待机并反复重置计时；新风降温使用全房间 `all` 判断和全屋观察时间，造成房间间相互影响。
9. 偏冷的“温度”贡献方也会被补上“偏热”标签；待客标记仅看文件存在，可能跨夜生效。

## 修正后的策略及合理性

| 场景 | 行为 | 判断理由 |
| --- | --- | --- |
| 门窗跑温已确认 | 已关保持关；制冷/除湿中请求关机；共享区域同步否决 | 保留门窗连续 10 分钟防抖，确认后不再为睡眠或待客继续制冷 |
| 房间舒适，AC 已关 | 保持关闭，即使同时有裸温偏热标签 | 以真实舒适需求决定启动，标签不直接等于指令 |
| 房间达标、连续卸载 | 默认 30 分钟后请求关机 | 给短暂卸载和传感器抖动留余量；出现带载、房间不适、设备会话改变或数据中断就重新计时 |
| 偏冷/过冷 | 不自动开机；运行时卸载，不再压低设定点 | 冷状态否决除湿制冷，避免越控越冷 |
| 有人且不适 | 连续 3 分钟需求确认，满足其他条件后开一台 | entering 不授权开机；减少短时路过和单次测量抖动触发 |
| 关机不足 30 分钟 | 保持关闭；缺失/无法解析关机时间也不开 | 保留手动关机保护，执行前再次校验实时状态 |
| 空房 | 不自动开机；现有机器卸载并按既有待机延迟关机 | 默认 30 分钟；客餐厅夜间确认灯全关仍用 5 分钟；历史预冷不再覆盖关机 |
| 夜间待客 | 保护本次夜间运行中的设备，仍接受跑温和长期卸载关机 | 待客文件不能替代真实人在信息来启动空调，也不能跨夜永久有效 |
| 新风可降温 | 各房间独立判断温差 ≥2°C，分别观察 30 分钟 | 一间房不符合条件不再取消另一间的新风优先；设备未确认启动的宽限仍为 2 分钟 |
| 偏湿/仅 CO₂ 高 | 不启动 AC；继续按现有新风/独立除湿机策略 | 空气问题不等于制冷需求；过湿只有在未舒适且未偏冷时才可授权 AC |
| 手动制热/送风/auto、软关、禁用 | 尊重手动模式与设备开关边界 | 自动调节仅管理 cool/dry；禁用保留明确关机一次的既有语义 |
| 输入过期/设备未知/需求消失 | 撤销旧自动队列，停止沿用旧决策 | 自动队列每轮重判、180 秒失效；用户排队指令优先 |

所有关机都是经过 `device_protection` 的请求。压缩机保护未结束时仍需等待，不强行绕过；等待期间每轮重新判断是否还需要关机。关机、开机和运行调节互斥。

## 负载证据与参数

优先使用设备的 `hvac_action=idle` 判断卸载；没有该反馈时，用有限数值的回风温度 ≤ 设定点估算。
这不是功率计读数，因此还同时要求房间体感达标。连续有效采样间隔最多 180 秒，超出视为中断。
决策快照新增 `rooms.<room>.control`，记录需求确认/卸载分钟数，设备快照标注负载判断来源。

新增 `engine.auto_start_confirm_min=3`、`engine.unloaded_off_min=30`，均可配置且至少 1 分钟。
3 分钟确认可过滤瞬时超标；30 分钟卸载关机相对保守，适合先验证房间的实际回温速度。
原体感目标 27.5°C、睡眠 03:00–10:00 的 28.5°C、体感与空调回风之间的设定点换算继续保留。
舒适带 `(目标-0.5, 目标]` 内只卸载/保持；体感低于或等于 `目标-0.5` 时必须主动校准回升，设定点取 `max(原设定点, ceil(回风), round(目标-0.5))`。例如睡眠目标 28.5°C、体感 25.6°C、回风 25°C、原设定点 26°C，应调到 28°C；不能因回风低于原设定点而继续维持 26°C。原设定点更高时不反向降低。持续带载且偏热时等待到位，不再逐分钟无止境降设定点。
